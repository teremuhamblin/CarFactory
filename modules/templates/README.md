# Dossier templates/

Ce dossier contient les modèles officiels CarFactory v2.x pour créer rapidement
de nouveaux modules et plugins compatibles avec le moteur.

Contenu :
- module_template/ : structure standardisée pour un module
- plugin_template/ : structure standardisée pour un plugin

Ces templates garantissent une cohérence militaire, une architecture propre,
et une compatibilité totale avec l’API interne du moteur CarFactory.
