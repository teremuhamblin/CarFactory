# Modules CarFactory v2.0

Modules tactiques utilisés par le moteur principal.

## Contenu
- diag_basic.sh — Diagnostic basique
- diag_engine.sh — Diagnostic moteur thermique
- diag_hybrid.sh — Diagnostic hybride
- diag_ev.sh — Diagnostic électrique
- obd_core.sh — OBD-II standard
- obd_extended.sh — OBD-II avancé
- telemetry_local.sh — Télémetrie locale
- report_advanced.sh — Rapport avancé
- bootcheck.sh — Vérification au démarrage

## Objectif
Fournir des fonctions spécialisées, chargées dynamiquement par `carfactory.sh`.
